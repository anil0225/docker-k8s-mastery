What is a Container, Actually? (Linux Namespaces Isolation)

A container is not a virtual machine. It is a standard Linux process running directly on the host kernel, restricted by 7 kernel Namespaces that control what resources the process is allowed to see.

Select Linux Kernel Namespace:
C Syscall Definition: Linux 2.6.24+ 
pid = clone(child_fn, stack_top,
    CLONE_NEWPID | CLONE_NEWNET |
    CLONE_NEWNS  | CLONE_NEWUTS |
    SIGCHLD, NULL);

Other fundamental syscalls: unshare() (detach current process) and setns() (join existing namespace, e.g. docker exec).

Cgroups v2 & CFS CPU Bandwidth Throttling Calculator

Why do microservices encounter mysterious 200ms p99 latency spikes even when average CPU utilization is only 30%? Linux CFS enforces quotas strictly within 100ms periods. Multi-threaded applications consume their allocated quota in milliseconds and get frozen by the kernel.

Container & Kubernetes Production Architectural Patterns

Proven enterprise patterns for zero-downtime rolling updates, micro-sized secure images, native sidecars, and resilient workloads.

Multi-Stage Distroless Dockerfile

1.2GB → 38MB (-97%)

Compile in an isolated build container and copy solely the stripped static binary into a distroless runtime image. Removes package managers (apt, apk), shell (/bin/sh), and root privileges.

Guarantees: Zero CVE attack surface, runs as unprivileged UID 65532.

Graceful Shutdown & preStop Hook

Zero 502/504 Errors

Kubelet sends SIGTERM concurrently as kube-proxy unlinks endpoints. Inserting a preStop: exec: sleep 10 delays SIGTERM until iptables propagates, draining in-flight requests cleanly.

Mandatory for zero-downtime rolling updates.

Native Restartable Sidecars (1.28+)

Lifecycle Determinism

Configuring initContainers.restartPolicy: Always ensures proxy agents (Envoy, Vault Agent, FluentBit) initialize before the main container boots and terminate after it halts.

Eliminates proxy race condition failures.
